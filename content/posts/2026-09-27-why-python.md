## 为什么第一篇写给 Python

本站第一篇正式文章。按理该讲 STM32 丢字符的血案，或者我挪那条光带着色器的七天——两件都比 Python 显得有技术含量。但我没犹豫：**Python 是我的计算机启蒙。** 我人生第一行真正跑起来的代码就是它写的。它在我完全不懂机器的时候，先允许我把一句话变成屏幕上一行动作；后来学的每样东西，说到底都是在给那第一行代码补注释。

还有个技术性理由：这个博客的后端是 FastAPI。你现在看到的搜索、标签、RSS，全跑在那门"据说慢得要死"的语言上。**没有 Python，这个博客会以另一种形式存在——以我退学的形式。**

## 一、它确实慢，但它把账算在了别处

一个循环比 C 慢几十到几百倍，我不替它狡辩。天天在 168MHz 的板子上抠周期的人，对这事有生理性抗拒。

但开销从来是两本账：**机器的时间**，和**人的时间**。机器时间便宜——我一个月服务器比一杯奶茶贵；人的时间贵——尤其是凌晨两点的那种。C 让你在机器面前省下三微秒，Python 让你在 deadline 面前省下三小时。

而且它压根不打算亲自表演算得快。NumPy 是 C，`re` 是 C，FastAPI 底下压着 uvloop。**你写的 Python 不是乐器，是指挥棒**——语法层慢一点，换来调度几十万个已经优化到极致的 C 工人，还不交社保。

## 二、几件只有 Python 人才知道的事

这些不会出现在第一章，但知道之后你会偏爱这门语言。

**缩进不是装饰，是法律。** 别家的语法糖，在 Python 里是强制排版。第三天你会骂它多管闲事，第七天开始用空行分段，第十四天写 C 时因为缩进乱了而心里发毛。它其实在偷偷教一件事：**代码是给人读的，只是顺便给机器执行。**

**`True + True` 等于 2。** 因为 `bool` 是 `int` 的儿子——`(<class 'bool'>, <class 'int'>, <class 'object'>)`。Python 的类型是一张家谱，不是十个互不相认的箱子：任何东西往上数三代都能叫 `object`。

**`0.1 + 0.2` 不等于 `0.3`**，它给你 `0.30000000000000004`。不是 Python 笨，是二进制小数本来就只能近似——它只是把这件事在你人生第一次加法上就摊开了。

**切片极其宽容，索引极其严格。** `nums[1:99]` 对一个只有三个元素的列表照样交货，一声不吭；`nums[99]` 立刻 `IndexError`。范围的事它让着你，越界的事它不商量。顺手一句 `nums[::-1]` 就能把列表倒过来。

**`is` 和 `==` 是两回事，而且 CPython 会骗你。** `is` 问"是不是同一个东西"，`==` 问"是不是一样"。我为了写这段刚做实验：分开赋值的 `256 is 256` 是 `True`，连 `1000 is 1000` 也是 `True`——我被常量折叠优化糊弄了，还得意地以为抓到了语言的把柄。

**默认参数只创建一次。** 我两次调用都只传了一个参数，第二次却端出了两个元素：

```python
def add(item, bucket=[]):      # 这个空列表只创建一次，所有调用共用
    bucket.append(item)
    return bucket

print(add(1))   # [1]
print(add(2))   # [1, 2]   ← 我明明没传第二个参数啊？？
```

这是 Python 唯一会主动背刺人的地方，而且专挑聪明人下手。

这些坑有个共同点：**都不是语言的错，是"名字和对象到底什么关系"在你脑子里还没成形。** 等我在 C 里第一次看见值拷贝和 `memcpy` 才反应过来——Python 早把"变量是贴在对象上的标签"教给我了，只是当时不收学费。

## 三、它的报错是一封信，C 的是律师函

Python 的报错像一封写给收信人的信：`TypeError: unsupported operand type(s) for +: 'int' and 'str'`——在哪儿、为什么、怎么办。C 的报错像律师函：`error: invalid conversion from 'int' to 'char *'`，不打算跟你讲道理，只通知你不合法，改掉。

第一门语言学的是律师函的人，第三周很容易被劝退；学的是信的人，会被"我居然自己看懂了错误"这件小事钩住很多年。我就是这样被钩住，然后一路钓到了嵌入式和后端。

## 尾声

Python 教我的最重要的东西不是语法，是那句：**先让它跑起来，再让它跑得快。** 完美版本永远不会发布，写完的草稿才会。现在这个博客已经跑起来了——有文章、有搜索、有 HTTPS，还有一台每天在到期倒计时上的免费服务器。速度嘛，以后再说。

谢谢 Python。下一篇写什么我还没定，大概是又一次凌晨三点的报错——等我先把它看懂。

—— 麻薯ta爸
